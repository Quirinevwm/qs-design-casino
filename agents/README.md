# Agents

> Autonomous tools and workflows for design intelligence

This space contains agents that automate workflows, gather insights, and support design work through AI-powered automation.

## What's here

Agents are self-contained tools that run independently to:
- Gather and analyze relevant information
- Automate repetitive workflows
- Deliver insights to design teams
- Support decision-making with context

## Available agents

### [AInews-fordesign-agent](./AInews-fordesign-agent)
Daily AI news digest agent that analyzes AI engineering updates through a design lens. Fetches updates from news.smol.ai, extracts top 3 insights about agents and models, and delivers them with focus on how they influence portal and CLI design.

---

*Agents are experiments in automation: they learn, adapt, and evolve as needs change.*
