# Contributing

Contributions are welcome! Here's how you can help:

## Filing Issues

Found something unclear or have suggestions? Open an issue with your thoughts or ideas for improvement.

## Submitting Pull Requests

1. Fork the repository
2. Create a branch for your change (`git checkout -b improve-design-process`)
3. Make your changes and commit with a descriptive message
4. Push to your fork and open a Pull Request

## What to Contribute

- Design frameworks and methodologies you've found useful
- Agent improvements or new autonomous tools
- Guidelines for working with AI in design contexts
- Documentation improvements and clarifications
- Examples and case studies from your own work
