FAQS

  1. Is OpenDesign free?+

    The desktop app is free and open source under Apache-2.0. Running it with a local coding agent or your own API key costs nothing extra from OpenDesign; your agent or model provider bills you as usual. OpenDesign Cloud, the hosted model service, comes with paid plans that include monthly model credits. See Pricing for current plans.

  2. Does OpenDesign run on macOS and Windows?+

    Yes. macOS 11 Big Sur or newer on Apple Silicon and Intel, and Windows 10 or 11 (x64) as an installer or a portable zip. There is no Linux build on the download page; on Linux you can run OpenDesign from source. If the download button can't detect your system, pick your build from the list.

  3. Do I need an account or an API key?+

    Not to start. Pick a local coding agent or your own API key on the Home screen and begin without signing in. OpenDesign Cloud needs an OpenDesign account and a plan with credits, but no provider key and nothing to install. One note: your own API key generates designs but can't edit files in your project; use a local agent when you need that.

  4. Do I need to know how to code?+

    No. Describe what you want, pick a design system, and review the result in the preview. Refine by asking again, or select elements and edit them directly. Setting up a local coding agent or an API key takes a few minutes. Turning a prototype into a production app is still engineering work.

  5. Where do my files and data go?+

    Projects live in a folder on your computer as HTML, CSS, and related files. Your prompts and context go to the agent, provider, or OpenDesign Cloud you chose. A share link publishes that file online. Product analytics is on by default and can be turned off in Settings → Privacy. See the Privacy Policy for details.

  6. What can I export from OpenDesign?+

    Standalone HTML, PDF, and PNG. Decks also export as editable PowerPoint. You can also keep editing in OpenDesign, open the files in your editor, or hand the project to your coding agent. There is no Figma export.

  7. Can I use OpenDesign with my team?+

    Yes. Start on your own and share files or a share link. Team plans add a shared workspace where members view and comment on projects and use shared design systems and plugins. For a larger rollout, talk to us.
